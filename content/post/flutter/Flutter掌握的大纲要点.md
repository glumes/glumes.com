Flutter 的掌握要点：

- 常见 UI 控件的使用

能够用常见的 UI 控件来组装一个应用界面，一些控件是怎么用的，要掌握好。

* 状态管理：

掌握不同状态管理的实现方式。从原生的 InheritedWidget 使用，到封装的 provider ，再到 riverpod 的使用，以及 getx 的使用。

掌握这些框架的优缺点，便于后续能够用在自己的开发中。

* Flutter 插件开发

要掌握工程上的内容，比如 Flutter 的 FFI 使用，以及插件工程的开发。通过 Flutter 来衔接 C++ 代码。
