日志打印基础使用

在 FFmpeg 中提供了 av_log() 方法去打印日志，它的函数声明如下：

1void av_log(void *avcl, int level, const char *fmt, ...)

其中 level 参数指的是日志级别，后面的 fmt 和 ... 代表日志内容，和调用 print 打印信息一样。

具体使用如下：

1av_log(nullptr,AV_LOG_INFO,"this is INFO log color");
2av_log(nullptr,AV_LOG_DEBUG,"this is DEBUG log color");
3av_log(nullptr,AV_LOG_WARNING,"this is WARNING log color");
4av_log(nullptr,AV_LOG_ERROR,"this is ERROR log color");

与 Android 日志类似，FFmpeg 也有多种级别的日志。

1#define AV_LOG_FATAL     8
2#define AV_LOG_ERROR    16
3#define AV_LOG_WARNING  24
4#define AV_LOG_INFO     32
5#define AV_LOG_VERBOSE  40
6#define AV_LOG_DEBUG    48
7#define AV_LOG_TRACE    56

看到 INFO、DEBUG、ERROR 这些级别是不是有似曾相识的感觉。

这些数值都是 8 的倍数，按照从小到大的顺序递增。

日志打印级别设置

在 FFmpeg 中可以设置和获取当前日志打印的级别。

1// 设置日志打印级别
2void av_log_set_level(int level);
3// 获取日志打印级别
4int av_log_get_level(void);

比如设置了当前级别是 AV_LOG_INFO ，那么凡是级别低于它的都不会打印出来了。

那么什么级别算是更低的呢？数字越小的级别越高，数字越大的级别越低。

比如设置了 AV_LOG_INFO 级别，它的值是 32 ，那么 AV_LOG_DEBUG 级别的日志就不会打印，它的值是 48 ，级别更低。而 AV_LOG_ERROR 就会被打印，它的值是 16 ，级别更高。

自定义日志打印

在 FFmpeg 中可以通过 av_log_set_callback 函数来注册一个日志回调，在回调中自定义日志打印方式。

av_log_set_callback 的函数声明如下：

1void av_log_set_callback(void (*callback)(void*, int level, const char* fmt, va_list));

它的参数是传一个函数指针，其中 level 指定了日志回调的级别，根据不同级别做不同操作，fmt 和 va_list 就是回调的日志内容了，和 print 函数相似。

以下就是具体的操作：

 1static void log_callback(void *ptr, int level, const char *fmt, va_list vaList) {
 2    switch (level) {
 3        case AV_LOG_DEBUG:
 4            logD(fmt, vaList);
 5            break;
 6        case AV_LOG_VERBOSE:
 7            logV(LOG_MAGENTA, fmt, vaList);
 8            break;
 9        case AV_LOG_INFO:
10            logI(fmt, vaList);
11            break;
12        case AV_LOG_WARNING:
13            logW(fmt, vaList);
14            break;
15        case AV_LOG_ERROR:
16            logE(fmt, vaList);
17            break;
18        default:
19            log(fmt, vaList);
20            break;
21    }
22}

在 switch 做日志级别的分发处理，具体的打印方法教给宏定义的函数。

注意的是，如果注册了自定义日志打印，那么除了我们调用 av_log 方法会打印日志之外，FFmpeg 内部的一些日志信息也会通过自定义的方法打印出来。

自定义日志打印颜色

一般来说，日志打印都是通过宏函数来定义的。

1#define logD(format,...)        \
2logging(LOG_GREEN,format,##__VA_ARGS__)

其中 ##__VA_ARGS__ 意思就是可变参数宏，对应函数里面的三个点可变参数 ... 。

具体的函数实现如下：

 1static void logging(const char * color ,const char *fmt, va_list vaList)
 2{
 3    // 设置日志打印颜色
 4    printf("%s [av-beginner]: ",color);
 5    // 打印内容
 6    vprintf( fmt, vaList );
 7    // 结束日志颜色设定
 8    printf(LOG_NONE "\n" );
 9}
10
11static void logging(const char * color ,const char *fmt, ...)
12{
13    va_list vaList;
14    va_start( vaList, fmt );
15    logging(color,fmt,vaList);
16    va_end(vaList);
17}

这里面涉及到可变参数以及日志颜色打印的内容，展开说一下日志颜色打印。

在终端的字符颜色是由转义序列控制的，比如终端中要换行，那么转义序列就是 \n 操作，对于颜色控制同样如此。

具体的显示格式如下：

\033[显示方式;前景色;背景色m输出字符串\033[0m

或

\e[显示方式;前景色;背景色m输出字符串\e[0m

在调用 print 函数打印信息时，就按照以上的方式即可，比如：

1// 打印红色的日志内容
2printf("\033[0;31m print red color log \033[0m\n") ;

以上就可以打印出红色的日志信息，具体的关于显示方式、前景色、背景色这些内容，后续的文章再接着说了。
